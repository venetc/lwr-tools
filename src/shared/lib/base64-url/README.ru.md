# base64-url

[English](README.en.md) · **Русский**

Байты ↔ текст base64url: текстовый вид бинарных кодов.

base64url использует `-` и `_` вместо `+` и `/` и не пишет паддинг `=`, поэтому код вставляется в URL, сообщение в чате или имя файла как есть, без экранирования.

## Использование

```ts
const text = toBase64Url(Uint8Array.of(1, 2, 3));
const bytes = fromBase64Url(text);
```

## API

| Функция | Аргументы | Результат |
|---|---|---|
| `toBase64Url(bytes)` | байты | текст base64url без паддинга |
| `fromBase64Url(text)` | текст без паддинга | байты; `null` для пустого текста, символов вне base64url или длины, в которую не кодируются никакие байты |

Декодирование не обрезает пробелы: вызывающий обрезает текст, полученный от пользователя.
