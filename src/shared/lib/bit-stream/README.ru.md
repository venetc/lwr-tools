# bit-stream

[English](README.en.md) · **Русский**

Запись и чтение значений, упакованных побитово, без выравнивания по байтам: 5-битное число занимает ровно 5 бит. Нужно, чтобы бинарные коды были короткими.

Биты идут старшим вперёд — и внутри значения, и внутри байта.

## Использование

```ts
const writer = createBitWriter();

writer.writeUint(3, 5);
writer.writeString('Overwatch', 5);

const reader = createBitReader(writer.toBytes());
const classCode = reader.readUint(5);
const name = reader.readString(5);
```

## Райтер

`createBitWriter()` возвращает `BitWriter`:

| Член | Что делает |
|---|---|
| `writeUint(value, bits)` | пишет младшие `bits` бит значения; старшие биты отбрасываются |
| `writeString(text, lengthBits)` | пишет длину в байтах UTF-8 в `lengthBits` бит, затем байты; текст длиннее `2^lengthBits − 1` байт обрезается по границе символа, никогда внутри него |
| `append(writer)` | дописывает всё записанное в другой райтер, без его паддинга |
| `toBytes()` | записанные биты байтами; последний байт дополняется нулями |
| `bitLength` | число записанных бит |

## Ридер

`createBitReader(bytes, bitStart = 0, bitEnd = bytes.length * 8)` возвращает `BitReader` по этому диапазону бит:

| Член | Что делает |
|---|---|
| `readUint(bits)` | читает беззнаковое число |
| `readString(lengthBits)` | читает строку, записанную `writeString` |
| `readSection(bitCount)` | возвращает ридер только по следующим `bitCount` битам и сдвигает текущий ридер за них |
| `isOverrun` | какое-то чтение вышло за конец |
| `remainingBits` | сколько бит осталось после текущей позиции |
| `isComplete` | данные прочитаны ровно до конца: ничего не осталось, выхода за конец не было |

## Чтение за концом

Ридер никогда не бросает ошибку. Чтение за концом даёт `0` или пустую строку, ставит позицию в конец и выставляет `isOverrun`. Поэтому парсер читает все поля подряд и проверяет результат один раз — `isComplete` или `isOverrun`, — а не после каждого чтения.

У ридера секции свой диапазон: выход за конец секции выставляет `isOverrun` только у него. `readSection` за концом родителя даёт пустой ридер и выставляет `isOverrun` у родителя.
