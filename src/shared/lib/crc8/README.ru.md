# crc8

[English](README.en.md) · **Русский**

Контрольная сумма CRC-8 от байтов: один байт, который ловит случайные изменения данных — опечатку в символе, обрезанный или склеенный код.

Параметры: полином `0x07` (x⁸ + x² + x + 1), начальное значение `0`, без отражения, без финального XOR — обычный CRC-8 (SMBus).

## Использование

```ts
const payload = Uint8Array.of(1, 2, 3);
const checked = Uint8Array.of(...payload, crc8(payload));

const isIntact = crc8(checked.subarray(0, -1)) === checked[checked.length - 1];
```

## API

| Функция | Аргументы | Результат |
|---|---|---|
| `crc8(bytes)` | проверяемые байты | контрольная сумма, 0–255 |

## Что ловит

- Любой один изменённый бит и любое нечётное число изменённых бит.
- Любую серию изменённых бит длиной до 8 — например, один неверный символ base64url.
- Прочие случайные повреждения пропускает с вероятностью 1 к 256.

Защищает от случайностей, не от подделки: подходящую сумму может посчитать кто угодно.
