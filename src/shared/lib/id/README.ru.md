# id

[English](README.en.md) · **Русский**

Случайные id для объектов, созданных во время работы приложения: билды на странице, уведомления. Различают объекты в пределах одной сессии и никогда не сохраняются и не передаются.

## Использование

```ts
const build = { id: createId(), name: 'Tester' };
```

## API

| Функция | Результат |
|---|---|
| `createId()` | случайный UUID v4, например `3f2b8c1e-9a4d-4e7f-b2c6-5d8e1f0a7b93` |

## Почему не `crypto.randomUUID`

`crypto.randomUUID` есть только в безопасном контексте (HTTPS, localhost) и в новых браузерах; открытие dev-сервера по IP в локальной сети его ломает. `createId` собирает тот же UUID v4 на `crypto.getRandomValues`, который работает везде.

## Не для сохраняемых данных

Данным, которые попадают в коды, файлы или хранилище, нужны номера, не меняющиеся между версиями, — как номера `code` у абилок и классов. Случайный id меняется при каждом запуске и сломал бы всё, что с ним сохранено.
