# panel-scroll

[English](README.en.md) · **Русский**

Прокручивает страницу к панели элемента списка, например из навигации по панелям на странице. Панели собираются через template ref, поэтому в документе ничего не ищется и id элементов не нужны.

## Использование

```ts
const { panelRef, scrollToPanel } = usePanelScroll();
```

```vue
<NotePanel v-for="note in notes" :ref="panelRef(note.id)" :key="note.id" />

<NoteNav :notes="notes" @select="scrollToPanel" />
```

## API

| Функция | Аргументы | Результат |
|---|---|---|
| `usePanelScroll()` | — | `{ panelRef, scrollToPanel }` |
| `panelRef(id)` | id элемента | функциональный template ref панели элемента: элемент или компонент |
| `scrollToPanel(id)` | id элемента | прокручивает панель к верху окна |

## Поведение

- Прокрутка плавная, а если пользователь предпочитает меньше анимации — мгновенная.
- Нерендеренная или размонтированная панель игнорируется.
- Отступ от верха окна задаёт `scroll-margin` панели, например под липкой шапкой.

## Ограничения

- Один вызов на список: id элементов должны быть уникальны внутри него.
- Прокручивает страницу или ближайшего прокручиваемого предка, как `scrollIntoView`.
